# 🌐 Responsive Landing Page

## 📌 Project Overview

This project was developed as part of the **SkillCraft Technology Web Development Internship (Task 01)**.

The objective of this task was to create a **responsive landing page** with an interactive navigation menu that changes its appearance when the user scrolls or hovers over menu items.

The application is built using **HTML5, CSS3, and JavaScript** with a focus on responsive design and user-friendly navigation.

---

## ✨ Features

- 🎨 Responsive Landing Page
- 📌 Fixed Navigation Bar
- 🔄 Navigation Bar Changes Color on Scroll
- 🖱 Hover Effects on Navigation Links
- 📱 Mobile-Friendly Responsive Design
- 💻 Clean and Modern User Interface
- ⚡ Smooth Scrolling Experience

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
